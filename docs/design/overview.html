Geometer Design Overview

Geometer is a native OCCT-based geometry engine with a thin C ABI, a Python package (wn-geometer) built on that ABI, and WASM builds of the same core for browser use. Design detail lives in the Markdown documents in this folder:

  • step-geometry.md — STEP model loading, bounds, meshing, HLR projection
  • planar-geometry.md — planar boolean/offset solving (vendored Clipper2)
  • c-abi.md — the stable C ABI exposed by libgeometer
  • python-package.md — ctypes bindings and the public Python surface
  • wasm.md — emsdk builds and browser/node interfaces
  • cli.md — the geometer command-line tools
  • binary-formats.md and json-formats.md — interchange formats
  • dependency-cache.md and distribution.md — OCCT binary cache and dist policy
  • interface-policy.md — naming and compatibility policy for public surfaces

Decisions with lasting consequences are recorded as ADRs under docs/geometer/adr; requirements live under docs/geometer/requirements.
