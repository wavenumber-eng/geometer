STEP media compatibility

Input MIME-value parsing and new producer model/step emission follow ADR-020. Ordered input declarations retain the legacy spelling. AP242 descriptor readers admit both bare spellings; this does not promote structural-only save. Operation availability and dispatch remain unchanged.
