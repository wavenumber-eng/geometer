Geometer Test Strategy

The test strategy covers native, Python, TypeScript, Rust, WASM, contract, package, and release surfaces.

Rack And Signoff

Rack strata are the test index of record. L99 signoff checks formatting, types, complexity, locks, versions, and repository hygiene.

Lanes And Parity

Native C++ and Python lanes validate the executable and bindings. Browser and Node lanes validate WASM behavior and cross-transport byte parity.

Fixtures, Assets, And Oracles

Governed packet fixtures, contract vectors, demo assets, and expected-result oracles provide deterministic regression evidence.

Coverage And Evidence

CTest, pytest, Rack, package validation, and qualification reports provide coverage evidence. Missing or deferred surfaces remain explicit in governed records.
