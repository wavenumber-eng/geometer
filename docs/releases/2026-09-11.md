# Geometer 2026.9.11

Release identity: `v2026-09-11`; Python/runtime and Rust/TypeScript client
version `2026.9.11`; C ABI generation `20260911`.

## Illustration performance and drawing geometry

Native illustration avoids repeated number formatting, vertex/material keys
and temporary allocations. Fast HLR reuses triangle-search bookkeeping and
uses faster deterministic vertex welding; fast mesh shadow reuses sweep ranks.
Python numeric-array codecs retain strict validation while avoiding repeated
descriptor dispatch and error-path construction. Illustration requests validate
their mesh input once before creating the IPC attachment.

The additive `geometry.mesh_illustration_geometry.a0` operation returns ordered,
colored 2D surfaces and linework without generating SVG. Direct C++, Python,
Rust, TypeScript and full browser WASM expose the drawing API. A Python Canvas
example demonstrates using the geometry with a custom renderer. Existing SVG
and geometry output share preparation, shading, visibility and fusion.

Captured native comparisons retain exact complete illustration results and
full-precision linework across 398 posed inputs. In single paired four-worker,
uncached SVG board runs, the final follow-up reduced Loz Old Man from 52.3 to
37.0 seconds, NXP FRDM i.MX93 from 122.6 to 102.9, and OV Tech PiMX8 from 51.2
to 42.7. RT Super C1 remained around 10 seconds. These are workload-specific
measurements, not latency guarantees. All 12 board SVGs were byte-identical.

Install `wn-geometer==2026.9.11`. Use matching generated clients and runtimes:
older clients reject the expanded operation catalog during handshake. The
existing SVG interface remains available. OCCT stays at 8.0.1; tessellation
behavior and its partial-result policy are unchanged.

Native examples, generated browser clients, standalone and hosted demos are
rebuilt with this release. The release workflow now rebuilds every retained
hosted browser demo; the optional Python viewer lock uses the matching package.

See the [drawing API](../design/mesh-illustration-geometry.md) and
[measurement record](../research/illustration-performance.md) for API semantics,
timing scope and memory tradeoffs. Release workflows validate all supported
native platforms, wheels, WASM and cross-transport parity before PyPI publication.
