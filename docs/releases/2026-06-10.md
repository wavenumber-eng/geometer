# Release Notes: 2026-06-10

## `2026.6.10`

### Dependency And CI Update

- Geometer now builds against OCCT `V8_0_0`.
- OCCT native and WASM dependency installs can be restored from the Wavenumber
  R2 dependency cache before falling back to source builds.
- The manual `OCCT Dependency Cache` GitHub workflow can publish Windows x64,
  Linux x64, Linux ARM64, macOS ARM64, and WASM OCCT archives to R2.

### Release Signoff

- Added Lizard complexity checking to L99 release signoff.
- Added reproducible `clang-format` tooling through the project `uv` dev
  environment.
- Updated GitHub workflows for Node 24-capable action majors.

- Release tag: `v2026-06-10`
- Python package: `wn-geometer==2026.6.10`
- C ABI generation: `20260610`
