# Log: scalar encoder linear-work remediation

Independent review accepted the frozen scalar byte grammar but found that
per-byte whole-bigint shifts made emission quadratic under a linear work
reservation. Magnitudes now use Boost's linear `export_bits` path directly into
the fully pre-reserved output buffer; canonical zero still emits no magnitude
byte.

A negative 137-bit rational golden locks its 18-byte minimal big-endian
magnitude, sign, record length, denominator, and padding. Its 48-byte scalar
encoding succeeds with exactly 384 work units and a 383-unit budget fails before
emission with no work or storage retained. Native and Emscripten reproduce the
same complete bytes and boundary outcomes.

Scalar decoding, the construction DAG/artifact, expression arithmetic, and
production integration remain gated pending independent acceptance.
