# Geometer 2026.9.10

Release identity: `v2026-09-10`; Python/runtime version `2026.9.10`; Rust and
TypeScript client version `2026.9.10`; C ABI generation `20260910`.

## Tolerant colored STEP tessellation

`geometry.model_tessellation.a0` now returns usable faces with warnings when
completed meshing encounters individual face failures. This is the default;
send `allow_partial=false` when a complete mesh is required. This changes the
previous default rejection of every partial tessellation.

The existing result `warnings` lists omitted-face counts, OCCT status flags
and bounded call-local face details. Returned mesh/triangle counts and hashes
describe only the usable output. Colors and placement are preserved, including
repeated occurrences. Failed face definitions are omitted at every placement.
Faces with no reliable triangles are not repaired or replaced.

This addresses imported models with microscopic sliver surfaces, such as the
USB connector regression fixture: the usable connector can be illustrated even
though one tiny face cannot be triangulated. The existing STEP-to-GLB path
continues to work as before.

Malformed input, failed transfers, no usable visible geometry, cancellation,
incomplete work, stale/unknown mesher status and output limits remain errors.
The persistent executable can service the next call after an operation failure.

Install `wn-geometer==2026.9.10`. Generated client contracts and the executable
must match. OCCT stays at 8.0.1; no dependency rebuild or new repair algorithm
is required. The release uses the existing native-platform, package, WASM and
cross-transport qualification workflows.
