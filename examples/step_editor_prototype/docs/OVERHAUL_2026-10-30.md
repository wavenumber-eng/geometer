# Editor overhaul (from STEP_Editor_Feedback_Professional.txt, 2026-10-30)

Goal: a professional, shippable editor: bug-free, fast, uncluttered, self-contained, cross-platform. Work order: the shell first (it touches every tool), then the tools 1 → 10, then the end passes. Each item is done → selftests → screenshot check → commit.

Status key: [ ] todo · [~] partial · [x] done

## B. Tools
- [x] B1 Health + Repair: sub-tools top-down, each with an instance count box: far from origin (recentre to geometric mean) · double vertices (merge distance, apply all) · Z-fighting faces (per instance, ← / → polarity) · openings (instance dropdown, fill mode: flat / interpolated / tangent / pocket) · star vertices (N-gon re-topology) · flipped normals · disjoint geometry · tiny edges / slivers · non-manifold · units. STEP issues first; STL / OBJ / PCB issues too.
- [x] B3 Z-Sit: plane picks (4 points default, 3 points, candidate plane, midplane of two parallel candidates, custom offset); XY origin (hull-center default, rect-center, centroid, point pick + which-point dropdown, custom point with editable XY); snap to vertices on by default with a threshold slider; Flip Z is a button
- [x] B4 Detect + Designate Pins: SMT / THR = Seed Tip, Detect Exact, Select Group (groups by normal + spacing, checklist dropdown, focused group brighter); CON / HEAD aligned the same (6 buttons); one concise ordering / naming block replacing Unibody Flow, Angle, Ordering, Name, Renumber, Set, aA, Predict; MARK = A / G / T / Unclassified; keep Number from footprint; pin list keeps only Delete and Clear
- [x] B5 Redefine Front: two toggle actions (point + line; IPC pin 1 + line); larger X-line snap; custom-rotation text box instead of ±90 / 180; drop Clear picks; keep Reset rotation
- [x] B6 Separate Unibody: three modes always at the top (Paint, Boolean, Growth); BODIES NOW and SPLIT PREVIEW in every mode, square, prezoomed
  - [x] Paint: paint a pin, Stage exact paint copies (find every matching face group), multiple seeds, the paint tools (+1 ring, split by colour …)
  - [x] Boolean: CREATE BOX / CREATE CYLINDER add the cut as soon as it's made; select and drag bounds; coplanar faces with outward normals count as inside; Find Matching places the same cut on every matching geometry
  - [x] Growth: grow from the pin seeds until a region boundary stops it, tuned
  - [x] Gap filler: no star N-gons; seal with 1–3 fitted planes where they close the opening, else plane + triangles; shared by all three modes
- [x] B7 Hitboxes: a shrink-wrap variant; the two previews side by side; drag handles on a clicked hitbox (quantized)
- [x] B8 Embedded Schematic: a pin table with three columns (designator · type acronym · schematic name); AUTO fills it, manual edits allowed
- [x] B9 Embedded Footprint: (a) generate from the model's Z = 0 slices with IPC math, or (b) load a footprint and solve the model onto it, storing footprint + transform
- [x] B10 Colors: one spelling ("Color" everywhere in the UI); a bigger palette with short names (Sn, Cu, Au, RED, BLU, MASK, EPOXY …) tiled tightly; Select similar; selected faces hatched so their colour shows through
