# Log: canonical scalar-value encoding feasibility

Added the first byte-level exact-backend conformance layer after independent
acceptance of canonical scalar identity. Rational and irrational values encode
the frozen scalar record with self-inclusive little-endian length, canonical
big integers, minimal four/eight-byte alignment, primitive coefficient order,
root ordinal, smallest dyadic interval, and signed Thom bytes.

The encoder computes every size and work bound with checked arithmetic before
allocation, reserves deterministic logical storage, and returns typed resource
failure with rollback. Native and Emscripten tests compare the complete bytes
for rational zero and canonical positive `sqrt(8)` and exercise a one-unit-short
work budget.

This does not yet implement scalar decoding, the normalized construction DAG,
the complete `GEXPA001` artifact, malformed vectors, expression arithmetic, or
production integration; those gates remain closed.

Validation passes all 16 native CTests, all six exact Emscripten tests, the 12
promotion-manifest tests, Ruff, Pyright, uv lock, clang-format, complexity,
repository audit, and docs.plans audit. Rack reports 71 passing tests and only
the intentional release-hygiene sentinel caused by this active temporary plan.
