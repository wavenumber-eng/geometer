# Log: occt-8-0-1-qualification

Implemented the first bounded OCCT exact-tag qualification slice without
changing the production dependency pin or enabling the analytic solver.

Added exact release-tag and isolated state-root support to the native and WASM
OCCT builders, an isolated Geometer distribution root, and
`scripts/qualify_occt.py`. The harness permits only `V8_0_0` and `V8_0_1`,
records annotated tag and dereferenced commit identities, source/cache build
evidence, native and WASM install sizes, bounded command timings and log
digests, full registered CTest results, feasibility digests, and all 19
governed synthetic native/WASM parity validators.

Qualification exposed and closed previously dormant WASM CTest harness gaps:
the repository ESM policy now uses `.cjs` for every registered Emscripten test
executable, fixture-backed tests preload their exact governed inputs, and
those tests use the same memory-growth and stack policy as the supported
browser module. This brought the complete suite to 38/38 native and 37/37
WASM for both exact OCCT tags.

Core evidence at the pre-commit qualification checkout is clean: both tags
produce feasibility SHA-256
`fba4ccb058efd96255703122e6d0d7c483ec71e07ef64757240f815d07fb5f6a`,
native and WASM output agree within each tag, and all 19 parity validators pass
for each tag. V8_0_1 adds 1,157,984 native install bytes and 1,115,658 WASM
install bytes relative to V8_0_0. Exact post-commit reports and the remaining
CLI/Python/GLB/browser/package/runtime/memory evidence are intentionally left
to the next slice before an acceptance or cache/pin decision.

Validation: focused OCCT Python tests 14/14, canonical native CTest 38/38,
Ruff, Pyright, repository audit, and plan audit pass. Rack reports 81 passed
with only the intentional active-plan hygiene sentinel. The production pin
remains `V8_0_0` and `production_solver_allowed=false`.
