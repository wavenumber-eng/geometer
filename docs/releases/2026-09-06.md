# Geometer 2026.9.6

Release identity: `v2026-09-06`; Python/runtime version `2026.9.6`; C ABI
generation `20260906`.

## Native illustration and clients

Colored STEP tessellation (`geometry.model_tessellation.a0`) and mesh
illustration (`geometry.mesh_illustration.a0`) are governed executable
operations. They run headlessly through `geometer serve --stdio`, the typed
Rust client, persistent Python, and Python one-shot helpers. Direct C++ callers
can link the same implementation. No JavaScript engine, WASM or GPU is needed.

The existing A0 input, style and result contracts are reused. TypeSpec owns the
shared values, operation catalog and attachment declarations. The complete
[STEP-to-SVG guide](../design/mesh-illustration-native.md) covers Rust and Python,
material colors, view transforms, shading, SVG options and resource limits.

Optional native HLR composition produces deterministic SVG with independent
visible-detail and outline controls. Consumers provide visible polyline HLR
for the same model, placement and view; the renderer handles layer ordering.
Surface fusion defaults to true. Raw mesh line overlays remain diagnostics,
not visibility-filtered HLR. Experimental ambient occlusion remains browser-only.

## Upgrade

Install `wn-geometer==2026.9.6` and import `geometer`. The wheel bundles the
native executable. Rust consumers can pin the `v2026-09-06` Git tag and select
the `geometer-client` package; crates.io publication is not part of this release.
Use matching generated clients and executable catalogs: a 2026.9.4 executable
does not support the new operations. Existing file CLI and browser APIs remain.

The intended native release platforms are Windows x64, Linux x64, Linux ARM64
and macOS ARM64. Qualification evidence and remaining gates are recorded in
[native API readiness](../developer/native-api-readiness.md).

## Documentation and examples

The README, IPC/interface guides, demo inventory and generated HTML reference
have been refreshed. Generated documentation adopts the shared ALX presentation;
the TypeSpec roadmap explicitly identifies operations and packed codecs that
still need migration.

The retained analytic planar Boolean solver is explicitly experimental and not
production-ready. Prefer Clipper2-backed polygon operations for visualization;
this release does not promote analytic or topology research APIs.

The optional Rust/egui/wgpu API Lab demonstrates the native-process workflow,
including progress, web-style view controls and original SVG export. It remains
source-only: GUI binaries are not added to release assets. C++ direct-link and
Python GUI demos are retained, with Fast detail/shadow controls. macOS GUI
acceptance and later C++ GPU work remain separate from headless API qualification.
