# Log: canonical standalone analytic job results

The typed result-packet boundary now makes semantic canonicalization mandatory.
The public encoder projects validated records before emitting bytes, and the
decoder independently projects and re-encodes a parsed packet before accepting
it. A mutation that remains structurally valid after swapping vertex allocation
order and repairing all affected references is therefore rejected instead of
becoming a second valid byte representation of the same result.

Standalone job extraction starts from a canonical batch, selects exactly one
job's diagnostics, regions, ring hierarchy, fragments, vertices, operand
events, and transitively referenced global source content, then densely rebases
every selected table and generated id. Relationship results are deliberately
omitted. Successful and failed jobs both produce self-contained canonical
packets, and extraction of an identical job alone or from differently arranged
mixed batches converges byte exactly.

A portable dependency-free C++17 SHA-256 implementation derives lowercase
standalone job digests. NIST empty-input and `abc` vectors protect the primitive;
Python's independent `hashlib` implementation verifies the native and
Emscripten result digests. The governed successful standalone vector is 996
bytes with SHA-256
`a934acefb39e7b397516b4ba948e3ded16f2d30c989a43271ee90883191f4f63`.
The governed failed-job vector is 616 bytes with SHA-256
`87f193938f0c1d60d8d196eb256adf0fa423f56175be63a61f0ef6cc8bebd46e`.
Canonical public encoding also makes the 1,220-byte record and semantic vectors
share SHA-256
`07019a4c2f94f8066db90b6f57bb3e5ea7801bb6b8bda63d8c7268dcad5bcb72`.

This closes the packet-boundary and standalone-digest infrastructure slice. It
does not enable analytic operation dispatch or claim the synthetic correctness
program complete. Closed-form geometry corpora, governed malformed-topology and
mutation cases, production native/WASM/IPC operation integration, generated
client projections, and MATZ adoption remain pending.
