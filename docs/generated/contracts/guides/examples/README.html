Test-only browser validation and benchmark harnesses live under tests/wasm/. The maintained build, packaging, panel, and publication boundaries are in docs/developer/browser-demos.md.

The WASM examples include a retained production-package Illustration Lab. It is available for design evaluation and regression testing, but is not a production renderer, supported public API, or commitment that Geometer will own the eventual illustration architecture.
