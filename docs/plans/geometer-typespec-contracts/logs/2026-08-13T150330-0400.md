Replaced the pilot's handwritten executable-control shapes with TypeSpec-owned
hello, welcome, request, reason, cancellation, protocol-error, shutdown-ack,
and embedded operation-catalog contracts. The normalized catalog now generates
strict JSON Schema, C++17, TypeScript, Rust, and HTML projections for those
roots. Integer generation preserves unsigned bounds in C++ and Rust and accepts
only exactly representable nonnegative integers in TypeScript.

The native server and Rust client now encode and decode these generated DTOs.

decode fails. New live failure tests cover incompatible negotiation, an
oversized fixed header rejected before payload allocation, broken stdout, and
explicit forced termination with pending work. The forced path found and fixed
a reader/terminator race where stdout EOF could mark the connection closed
before pending response channels were resolved.

platform executable on Windows x64, Linux x64, Linux ARM64, and macOS ARM64.

required multi-platform gate.
