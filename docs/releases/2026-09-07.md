# Geometer 2026.9.7

Release identity: `v2026-09-07`; Python/runtime version `2026.9.7`; Rust and
TypeScript client version `2026.9.7`; C ABI generation `20260907`.

## Externally supervised Rust processes

Rust desktop applications can now launch and contain `geometer serve --stdio`
through their own audited process boundary, then transfer async stdin, stdout,
stderr, and a lifecycle controller to `GeometerClient::from_process`. The
existing `GeometerClient::spawn` path remains the easy default and shares the
same negotiation and lifecycle implementation.

This enables Alexandria to assign a Windows Job Object before protocol traffic
starts. The generic controller also supports POSIX process-group or session
containment without duplicating Geometer's A0 framing or typed operations.

Construction, graceful close, forced termination, protocol failure, cancelled
cleanup, and final-client drop use bounded process and stream-task cleanup.
Interrupted cleanup remains retryable. The packaged example covers model
tessellation, Fast HLR, and HLR-composed illustration against the native
executable.

## Unified package identity

The Python wheel/runtime, CMake build, Rust client, TypeScript client, C ABI
generation, and native release bundles advance together. Install
`wn-geometer==2026.9.7`; Rust consumers can pin the `v2026-09-07` Git tag and
select the `geometer-client` package. Crates.io publication is not part of this
release.

The intended native platforms remain Windows x64, Linux x64, Linux ARM64, and
macOS ARM64. The release workflow builds, tests, packages, and attests each
platform from the tagged clean revision.
