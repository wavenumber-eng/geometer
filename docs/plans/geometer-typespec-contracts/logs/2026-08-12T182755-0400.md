# Log: analytic-planar-boolean joint review remediation

Remediated the first MATZ joint-review findings without enabling generic
transport implementation or adding production solver code.

The design now retains certified exact real-algebraic geometry and lineage
across every ordered Boolean stage. OCCT binary64 geometry selects topology
candidates only. The governed integer-nm normalization occurs once after the
final stage, so intermediate snapping cannot change a later Boolean result.

Result geometry remains endpoint-authoritative. Lines store shared integer-nm
endpoints. Circular arcs store shared endpoints, integer-nm radius, direction,
and major/minor branch, with a derived center. Full circles have a fixed
left/right split and traversal order. The normalized curve table and serialized
source-set hash remain removed.

The native and Emscripten feasibility test now asserts the twelve exact
endpoint/radius/direction/branch fragments for MATZ portable case 2. Its
five-line canonical signature is identical on both targets with SHA-256
`c21b03c1b42a6cb3212cec5b3051987f645e21062eddecc82d3e3b0e0fd6dfc7`
when hashed without the console's trailing line terminator. This is the
proposed case-2 feasibility oracle, not a production packet golden.

The joint design/test freeze remains pending MATZ's ratcheted observation
manifest and re-review. Independent technical review, TypeSpec source, packet
goldens, transport implementation, and operation promotion remain later gates.
