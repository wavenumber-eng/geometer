# Log: filtered-analytic-solver-design

# Governed transition-driven lineage remediation

Remediated the first filtered-lineage implementation after independent numeric,
performance, and integration review. The production stage no longer copies or
hashes the persistent coverage DAG and no longer unions one dense coverage root
per face. Each material component is traversed through its indexed dual edges;
newly exposed stage intervals and entering membership transitions emit each
region/operand association once. This keeps structural work sparse and avoids a
face-by-operand or dense-root quadratic path.

Surviving subtraction now comes from the active difference-stage coverage of
the empty-side face rather than only the boundary carrier memberships. Refilled
islands therefore retain responsible noncoincident and same-stage subtractors,
while later removal epochs do not revive overwritten subtractors. Authored and
compact source references are validated against their curve roles and governed
identifier shapes before arrangement, and input subtractive-effect references
are rejected; those references are synthesized only from validated difference
stage metadata.

Lineage fixed structural memory and work are admitted through the owned
selection/regions path before arrangement. The stage uses only exact-capacity
vectors and target-independent logical byte charges. An allocation-free count
pass checks raw source incidence and publication ceilings before reserving and
filling the canonical source table. Every stage/operand/source scan, coverage
node visit, material-component transition, edge/collapsed membership visit,
sort, unique, and publication traversal is charged. The active-removal stage
tree query is now also included in selection admission and telemetry.

Tests cover malformed source identities, remove/refill/remove epochs,
noncoincident and same-stage subtractors, coincident positive contributors,
isolated collapsed lineage, exact/one-short work and memory admission, exact
source-publication limits, and 1x/2x sparse scaling below 3x work and memory.

selection at SHA-256

Final 1 nm coordinate publication, operand outcomes, dispatch, and transport

non-primary oracle/fallback only.
