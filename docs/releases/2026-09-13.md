# Geometer 2026.9.13

Release identity: `v2026-09-13`; Python/runtime and Rust/TypeScript client
version `2026.9.13`; C ABI generation `20260913`.

## One-pass model illustration

The governed `geometry.model_illustration.a0` operation accepts an embedded STEP
attachment or a reusable analytic scene and returns a fused SVG illustration.
`geometry.model_illustration_geometry.a0` runs the same native pipeline and
returns renderer-neutral drawing geometry for custom SVG, Canvas, or other
consumers. STEP import, tessellation, Fast detail, Fast Mesh Shadow, visibility,
shading, and same-color surface fusion remain within Geometer; intermediate mesh
JSON no longer crosses executable IPC.

Analytic A0 sources cover planar extrusions with holes and arc segments, Z-axis
cylinders, spheres, definitions, occurrences, transforms, materials, and depth
ordering. STEP import retains usable faces on partial failures by default and
emits ordered warnings.

The direct boundary is 1.97 times faster than the previous three-operation path
on the OV Tech PiMX8 U16 model and avoids a 12 MiB intermediate mesh JSON
attachment. The complete no-cache ACR Toon run for that board improved from
20.48 seconds to 12.66 seconds.

Install `wn-geometer==2026.9.13`. Use matching generated clients and runtimes;
the negotiated catalog and C ABI generation advance together. OCCT remains at
8.0.1 and does not require rebuilding for these changes.
