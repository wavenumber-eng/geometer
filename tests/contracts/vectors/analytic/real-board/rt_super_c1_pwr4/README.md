# RT SUPER C1 PWR4 analytic request

This directory contains the publicly redistributable, geometry-only
`GMABRQ01` request derived from the pinned RT SUPER C1 `PWR4` physical copper
slice. Wavenumber authorized public redistribution under MIT with the
attribution `Copyright (c) Wavenumber LLC`.

The source CAD is excluded and is not included in this evidence set. The
request is accompanied by the canonical Appz exporter manifest, a replayable
external-real-board qualification corpus, and a bound local observation report.
The report was produced on an AMD Ryzen 9 5950X from a dirty Geometer build; it
is qualification evidence, not reference-machine or release-promotion evidence.

The directory intentionally does not duplicate the request as lowercase hex and
does not retain the full result packet. The expected result digest and decoded
result accounting are governed by `corpus.json` and the local report.
