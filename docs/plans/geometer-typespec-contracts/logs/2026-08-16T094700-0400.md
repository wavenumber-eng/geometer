# Log: filtered-analytic-solver-design

# Active-and-unseen lineage traversal remediation

Independent performance and integration review found that intersecting a
coverage root with a universe-wide unreported tree could revisit reported
active leaves when absent unreported operands were interleaved in the same
subtrees. Repeated lineage-epoch decreases could therefore create hidden
`O(faces * operands)` work despite emitting no new contributors.

The component traversal now builds one governed sorted edge/operand transition table,
then performs an iterative depth-first walk that applies transitions on entry
and reverts them on exit. Newly exposed stage ranges are enumerated once from
the destination persistent coverage root. After exposure, a generation-stamped
tree contains only operands that are both active on the current face and not
yet reported for the region. Range reporting therefore visits live output
paths rather than absent operands, and each region/operand association remains
single-emission.

Transition construction, sorting, apply/revert paths, fixed reporter tables,
and traversal frames are admitted with target-independent logical work and
memory. Exact publication reconstruction now accounts all four former
face-index roles plus the larger iterative traversal frame and both range
tails. A branch-dense 1x/2x fixture interleaves active central and absent remote
operands across alternating difference/refill epochs and stays below 3x
coverage visits and lineage work. The same connected subdivided case gates the
pre-arrangement exact/one-byte-short memory boundary. A publication-dense
many-to-many case independently pins the exact live publication phase and
rejects one byte short before allocating public lineage storage.

Native and Emscripten lineage bytes remain 3,672 bytes and match at SHA-256
`466fb955863a53de2686d2d373b3ae92bd787483f1f35bc9e940b85b7d409e18`.
The production path remains filtered, non-algebraic, coordinate-free in this
stage, and not dispatched. Operand outcomes, one-time 1 nm publication,
post-normalization topology validation, dispatch, and transport remain pending.
