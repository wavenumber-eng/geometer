# Geometer 2026.9.19

This release adds deterministic generic half-space clipping to the technical
illustration pipeline and publishes the affected operations as B0 interfaces.

It also includes the static native SDK and unified-transport work prepared for
2026.9.18. Every native target builds a relocatable static C ABI SDK candidate,
the native C ABI and executable IPC share one governed dispatcher and serialized
execution lane, and `geometer_serve_stdio()` supports application-hosted worker
processes without a sibling Geometer executable.

- Model and composed-mesh SVG/geometry operations clip after all source
  placements and affine transforms, before bounds, HLR, outlines, visibility,
  shading, and projection.
- Composed-mesh Fast HLR uses the same prepared fragment and publishes a digest
  that illustration composition verifies.
- Multiple planes, interpolated boundary normals, source material identity,
  deterministic degenerate removal, explicit empty success, and bounded work
  limits are supported. The only initial cap policy is `none`.
- A0 illustration operations remain strict compatibility adapters. Generic C
  ABI, executable IPC, and Worker framing remain A0 and select the B0 logical
  contract from the operation identity.
- Generated C++, Python, TypeScript, and Rust contracts/clients include the B0
  roots. Maintained examples and browser illustration workflows use B0.
- The browser Illustration Lab and egui Native Rust API Lab expose adjustable
  B0 clipping controls. Relocated static SDK qualification exercises an
  internal Rust direct-static sample without `geometer(.exe)`; that sample is
  not a separately published demo application.
- Release production rebuilds and qualifies Windows x64, Linux x64, Linux
  ARM64, and macOS ARM64 runtimes, install-tested Python wheels, and relocated
  static SDK consumers. WASM direct and Worker transports are qualified from
  the same immutable tagged source.

The release version is `2026.9.19`, the tag is `v2026-09-19`, and the C ABI
generation is `20260919`.
