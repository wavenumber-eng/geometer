# Log: exact topology replay and critical mutation sentinels

The synthetic-correctness program now has an independent semantic oracle for
normalized solver results. For each job, the oracle reconstructs published line
and circular-arc fragments as exact curves, including the circle center selected
by endpoints, radius, direction, and major branch. It sends those curves through
the exact arrangement, union-stage, and result-region pipeline, then matches
reconstructed rings back to claimed rings by complete fragment-occurrence sets.
Winding, depth, smallest strict parent containment, connected result regions,
and outer-ring ownership must agree. Jobs replay independently so coincident
geometry owned by different batch jobs cannot interact.

This is a solver-output promotion oracle, not hidden geometry work in the raw
codec. The structural/canonical decoder remains allocation-bounded; production
analytic dispatch must call the replay oracle before exposing a result packet.
Dispatch remains disabled.

The first explicit mutation lane covers six governed sentinels:

- reversed closed line winding;
- reversed two-half-circle arc winding;
- a hole assigned to a disjoint, non-containing root;
- two point-tangent components falsely represented as a parent/hole hierarchy;
- an island incorrectly collapsed into its surrounding outer component;
- removal of a contributor that leaves geometry unchanged but changes canonical
  lineage bytes; and
- substitution of ties-to-even for the governed ties-away nm rule.

The first five mutations deliberately preserve the structural record graph and
are rejected only by exact semantic replay. The lineage mutation remains
geometrically valid and is caught by the canonical packet digest. The tie
mutation is caught by the exact normalization oracle. Native and Emscripten
report the same ordered sentinel inventory. A linear nearest-even-component
ownership index and per-job ring/region lists remove repeated parent walks and
global per-job scans. A valid outer/hole/island fixture protects island
ownership, while 16,384-deep and 65,535-empty-job cases protect bounded
traversal. The updated analytic design digest is recorded in the promotion
manifest.
