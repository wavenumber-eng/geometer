# Geometer 2026.11.22

Geometer `2026.11.22` uses tag `v2026-11-22` and C ABI generation `20261122`.
Update the runtime and generated clients together so their catalogs match.

- Mesh illustration culls fully occluded and back-facing triangles before
  painter ordering and fusion. Fused surfaces keep the required paint order,
  and callers can set their own illustration work budgets.
- Fast HLR is the detail mode. Mesh Shadow and Fast Mesh Shadow provide
  outlines. Migrate `exact` and `poly` to `fast`, and use `fast-mesh-shadow`
  in place of `hlr-close`.
- The experimental analytic planar Boolean operation and its demos are
  retired. Clipper2 remains the supported polygon Boolean and offset path.
  Model illustration still accepts analytic 2.5D inputs.
- STEP producers use the standard `model/step` media type. Readers continue
  accepting the existing `application/step` spelling.
- The Rust client adds a supervised executable worker pool and optional
  disk-backed result caching, and requires Rust 1.89.

See the [changelog](../../CHANGELOG.md) for the complete list.
