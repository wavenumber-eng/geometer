# Assemble canonical packets on the filtered path

Added an owned filtered packet continuation from request records, trusted
lowered geometry, and canonical broad-phase pairs. It owns normalization,
copies the accepted 1 nm coordinates verbatim, validates the explicit old
vertex/boundary/ring/region maps, binds every used source tuple back to its
request operand and geometry or difference stage, assigns canonical record
IDs, encodes one standalone result packet, and computes its SHA-256 closure.
Failed governed jobs publish one job-only diagnostic and no partial geometry.

Production source kinds, roles, and references now live in a neutral header;
the exact implementation aliases those types instead of defining the packet
surface. The packet structural validator also replaces its prior Boost integer
chord check with bounded portable fixed-width arithmetic, so the normal packet
path no longer imports the exact/algebraic namespace.

Source sets, vertex incidence sequences, canonical ring rotations, and event
reference sequences use a fixed-capacity exact prefix trie with governed
open-address probes and lexicographic scalar ranks. Long common prefixes are
traversed once rather than inside variable-length sort comparators. Candidate-
bounded work and target-independent logical memory are reserved before
normalization; exact work/memory boundaries, early failure, irrational disk
intersections, compact and authored provenance, subtraction outcomes,
deterministic bytes/digests, and 1x/2x shared-prefix scaling are covered.

49/49. All ten filtered native/WASM parity validators passed; the new packet
