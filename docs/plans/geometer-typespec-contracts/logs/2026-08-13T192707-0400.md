# Log: exact root budget and Thom-zero remediation

Independent review found two gaps in the real-root feasibility slice. Root
isolation did not yet enforce the separately governed exact-predicate and
interval-refinement counters, and its interval-only Thom evaluation could not
emit an exact zero sign for a derivative sharing the selected root.

The exact budget now exposes monotonic `exact_predicate_calls` and
`interval_refinement_steps` dimensions with the catalog limits of 100,000,000
each. Every Sturm sign evaluation and infinity-sign examination charges a
predicate before evaluation, and every candidate dyadic-cell examination
charges a refinement step before work. Exhaustion returns the typed
`resource_limit_exceeded` result, retains executed counter consumption, and
rolls back temporary storage. Native and Emscripten tests cover late predicate
and refinement exhaustion plus retries against the same budget.

Thom evaluation now computes the exact polynomial GCD between the selected
root polynomial and each derivative. A Sturm count over the selected isolating
cell determines whether the shared root is present and emits zero exactly;
nonzero signs retain the exact constant-sign/root-count proof. The reducible,
square-free fixture `(x^2 - 2)(x^2 - 10)` protects zero second-derivative signs
at both `sqrt(2)` roots.
