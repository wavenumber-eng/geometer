# Log: geom-contract-alignment

Accepted the MATZ analytic planar Boolean request as a consumer-requirements
input and the first new capability after the complete `model_bounds`
infrastructure pilot. This does not freeze the MATZ request/result proposal:
Geometer owns the generic TypeSpec operation, analytic topology, separately
governed packed attachment format, normalization, provenance, diagnostics, and
solver choice.

Recorded the proposed stable operation identity
`geometry.analytic_planar_boolean_batch.a0`, retained existing sampled planar
and Clipper2 APIs, and prohibited an operation-specific bytes C ABI symbol. The
operation will use named attachments through the reviewed generic C ABI and IPC
transports.

Added a digest-locked compatibility-input snapshot for the `geom_a0` schema,
accepted Geom ADRs 0003 through 0005, and the MATZ requirements packet at source
revision `fabbf70e1970adb7fa74f3be64c4ef45e2b89154`. The source worktree had only
unrelated untracked generated material outside those contract paths. Geometer
does not read the sibling checkout during generation, build, or test.

The design slice now requires an OCCT feasibility prototype, exact analytic
line/circular-arc output, ordered add/subtract semantics, governed nanometer-grid
normalization, deterministic canonical bytes, provenance multiplicity,
fail-closed diagnostics, bounds and performance limits, and native/WASM/IPC
parity. Clipper2 may be a sampled non-authoritative oracle only.

The release handshake is explicit: Geometer proposes; MATZ reviews and supplies
fixtures; Geometer proves generated TypeScript/Python and transport parity;
Geometer ships an additive tagged release; MATZ pins and migrates; and MATZ's
solved-copper gate remains blocked until released integration passes. Candidate
artifacts are permitted for pre-release testing, not the production/default
switch.

Transport implementation remains disabled pending the already active
independent review. If analytic-planar design requires changing the digest-locked
generic transport packet or its browser export posture, that review gate must be
reopened before implementation.
