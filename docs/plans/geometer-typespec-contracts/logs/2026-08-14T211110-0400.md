# Log: analytic-planar-boolean-promotion

# Promotion slice 2a: GMABRQ01 request packet codec

First sub-slice of slice 2 (C++ server + shared vectors): the packed
`GMABRQ01` request-packet codec for
`geometry.analytic_planar_boolean.packet.a0`, mirroring the result-side
layout module conventions.

## Changes

- New `src/cpp/lib/geometer/analytic_request_packet.h` +
  `src/cpp/lib/analytic_request_packet.cpp`: decode, canonical structural
  validation, and unique canonical encode for all 13 request tables.
  Errors map one-to-one to the governed `[contract_diagnostic]` classes
  (`invalid_packet`, `invalid_id`, `invalid_reference`, `limit_exceeded`);
  any defect rejects the whole batch with no partial value, and encoding
  validates first and fails closed.
- Validation enforces the canonical wire contract: header/directory shape
  with 8-byte-aligned offsets, exact byte lengths, and minimum zero
  padding; strictly ascending job/query ids; preserved stage order with
  same-stage operands sorted by id; gapless owned-range partitions
  (jobs->stages, stages->operands, regions->hole refs, rings->vertices/
  segments); exactly-once geometry and ring ownership in owner-traversal
  order (rejecting unused records); closed/open ring structure; line/arc
  segment field coherence; nonzero shareable curve ids; one compact
  feature id space across disks/annuli/capsules/swept paths; A0 count and
  1..10^12 nm magnitude limits. Job-local geometric validity (arc
  coherence, containment, distinct capsule endpoints, coordinate span) is
  deliberately deferred to job-local failure per the design failure-scope
  matrix.
- Wired into `GEOMETER_LIB_SOURCES` (native + wasm) and
  `GEOMETER_EXACT_SOURCES`.
- New governed-style test `tests/cpp/analytic_request_packet_test.cpp`:
  480-byte unique empty batch, full exemplar exercising every table
  (region with hole, two disks, annulus, capsule, swept open path,
  shared-carrier arcs, two queries) with byte-identical
  encode->decode->re-encode, plus byte-mutation and records-level
  malformed cases covering all four diagnostic classes.

## Interpretation decisions flagged for review

- Canonical ownership read as: geometry-table records appear in
  operand-traversal order (`geometry_index` equals the running per-kind
  cursor) and ring-table records in owner-traversal order (region outer,
  then holes consecutively, then swept-path centerlines), which forces
  `ring_references` to be consecutive integers.
- Zero/degenerate magnitudes (`radius_nm == 0`, `inner >= outer`) classify
  as `invalid_packet`; magnitudes above 10^12 nm classify as
  `limit_exceeded`.
- Coordinate-span checks stay job-local (not batch-rejecting) and land in
  the lowering/orchestrator sub-slice.
