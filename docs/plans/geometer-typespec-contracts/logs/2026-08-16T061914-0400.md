# Log: filtered-analytic-solver-design

# Repeated-carrier admission remediation

The performance reviewer rejected the prior exact commit because its fallback
transition reservation multiplied all possible spans by the whole curve table.
That turned the normal shared carrier of each disk's paired semicircles into a
quadratic cross-job reservation and could reject a few hundred disjoint pads or
vias despite linear actual geometry.

The replacement bound is incidence-based. It starts with each curve's own line
or partitioned-arc membership segments, adds both curve incidences for every
possible LL/LC/CC intersection point, and adds at most two foreign endpoints per
curve for a same-carrier candidate. It is `O(curves + candidates)` and requires
no carrier-pair or all-curves scan. Disjoint 200/400-disk fixtures now succeed
under the default budget and assert sub-3x admission work, total work, and live
logical memory.

The same allocation-free candidate scan now validates strict global pair order
and uniqueness. Its fixed work charge was widened from five to six units per
pair to cover that comparison in addition to the worst-case shared-endpoint
checks. Duplicate and out-of-order sequences return `invalid_argument` with
zero arrangement work at both default and tight admitted memory budgets.

Focused native and WASM filtered Boolean-selection tests pass. Native/WASM
selection parity is exact at 12,360 bytes and SHA-256
`28d5387e04745a191376cd1b17163d9956865d0b5edbc3d448690cd42a031b6f`;
overlay and arrangement parity remain unchanged.

The complete native suites pass 45/45 in both build trees and the complete WASM
suite passes 44/44. Python passes 61/61 and promotion-manifest tests pass 15/15.
Ruff, Pyright, uv lock, clang-format, focused Lizard, diff hygiene, and the
wn-dev-std repository/plan/test/language/CI/compatibility audits are clean. The
parent commit's native runtime, clean-wheel, and 8/10 L99 results remain
applicable; the two L99 exclusions are still the pre-existing CCN-113 request
packet validator and the intentionally active plan.

Selected-boundary publication, complete lineage projection, final 1 nm
normalization, owned production dispatch, and transport integration remain
pending. The algebraic backend remains a non-primary oracle/fallback only.
