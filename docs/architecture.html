Architecture

Geometer provides generic CAD/kernel geometry operations through a C++17 library, native CLI, executable-backed Python package, and WASM C ABI targets. Maintained interface docs live under docs/design/.

Boundaries

  • src/cpp/lib/ owns reusable C++ geometry operations.
  • src/cpp/cli/ owns the thin native command-line wrapper.
  • python/geometer/ owns the public Python package.
  • scripts/ owns dependency, validation, and packaging helpers.
  • dist/ owns committed runtime artifacts only.

Standards Profile

Geometer uses tool.wn_dev_std.profile = "python-native-wasm". It inherits the C++ formatter, Ninja, CMake preset, clang-tidy, CTest, and ABI expectations from the C++ profile.
