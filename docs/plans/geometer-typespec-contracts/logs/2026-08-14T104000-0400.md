# Log: typed analytic result records and structural graph codec

portable C++17 value records. Its encoder and decoder read and write every
scalar explicitly in little-endian order, preserve the full unsigned 64-bit
identifier range, reject nonzero reserved fields and non-Boolean bytes, and
perform packet-size arithmetic before table allocation. The typed layer
round-trips an empty packet and a 1,220-byte all-record graph byte exactly.
