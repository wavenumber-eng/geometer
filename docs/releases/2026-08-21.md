# Release Notes: 2026-08-21

## `2026.8.21`

### Endpoint/radius analytic arcs

- Adds an exact endpoint/radius circular-arc construction for analytic planar
  regions, including deterministic minor and major selection.
- Preserves source operand, segment, and curve lineage through native and
  browser-WASM result publication.
- Provides the same generated contract and codec surface in C++, Python,
  TypeScript, and Rust while retaining the existing A0 packet layout.
- Keeps constant-width swept paths on their existing line and integer-center
  circular-arc subset; endpoint/radius swept-path support remains deferred.

The solver remains fail-closed when it cannot certify a common carrier, such
as coincident circles expressed through different endpoint pairs or mixed
center/radius constructions. It does not silently tessellate, approximate, or
repair those inputs.

### Build provenance

- Adds deterministic browser build attestations for the generated TypeScript
  package and browser WASM artifacts.
- Release automation rebuilds and validates native wheels for Windows x64,
  Linux x64, Linux ARM64, and macOS ARM64, rebuilds WASM, and requires exact
  native/browser analytic result parity before publishing.
