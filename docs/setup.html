Setup

Geometer is a mixed-mode Python, C++, and WASM project. The detailed developer setup guide is maintained at docs/developer/README.md.

Required Tools

  • Python 3.10 or newer for the package runtime.
  • Python 3.11 or newer for Rack-based development tooling.
  • uv for locking and development tool execution.
  • CMake 3.24 or newer.
  • Ninja as the default native generator.
  • A C++17 compiler for native builds.

Development Commands

uv sync --group dev
cmake --preset default
cmake --build build --config Release
uv run pytest tests/L99_release -q
python scripts/validate_native.py
python scripts/validate_python_package.py

Artifact Policy

Runtime artifacts are committed under grouped paths in dist/native/<platform>/ and dist/wasm/<target>/. Local dependency and build state such as .deps/, build/, build-wasm/, out/, and .venv/ must not be committed.

Dependency Cache

OCCT may be restored from the Wavenumber public binary dependency cache at https://artifacts.wavenumber.net. Restored archives are verified and extracted into .deps/; source builds remain the fallback.
