# Log: generated contract reference implementation

The pilot catalog now generates a committed offline HTML landing page, one page
per contract root, one page per operation, and a machine-readable site
manifest. Generated pages carry authority warnings, lifecycle state,
catalog-digest markers, schema/source/design links, presence/default intent,
constraints, nested declarations, and attachment limits.

The reviewed Wavenumber stylesheet and watermark are vendored. The public
stylesheet preserves the upstream layout and component rules while replacing
internally licensed Berkeley Mono declarations with the digest-locked OFL-1.1
Cousine regular and bold fonts; the OFL license is committed beside them. The
promotion manifest records both the upstream stylesheet digest and the adapted
vendored digest. The documentation-asset-licensing exit criterion is met.

Generation uses staging and exact file-set/byte comparison. The dedicated
`contract_docs` Rack stratum independently checks freshness, complete catalog
coverage, relative links, local schemas/sources, local font and watermark
resources, metadata, responsive CSS, and the absence of external runtime
dependencies.

Interactive browser smoke could not run because the in-app browser connection
was unavailable in this environment. Desktop and narrow visual verification
remains open, so the generated-HTML step and exit criterion are deliberately
not marked complete.
