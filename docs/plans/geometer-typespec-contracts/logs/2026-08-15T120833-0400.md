# Log: filtered-analytic-solver-design

## Human-Directed Solver And Numeric Policy Pivot

Project-owner review identified the primary product cases as PCB artwork and
documentation, resolved planar faces for 3D viewers, and PCB manufacturing
geometry. Speed is preferred, and deterministic bridge/collapse behavior at or
below 50 nm is acceptable. This is materially below the useful resolution for
the named consumers.

The owner explicitly rejected making the arbitrary-precision algebraic engine
the primary solution and asked to simplify the implementation. The observed
nested-radical normalization failure is therefore treated as evidence against
the exact-first production architecture, not as a request to raise its memory
budget.

ADR-013 supersedes ADR-012 for production implementation:

- retain integer nanometers and the 1 nm public output grid;
- use a fixed 50 nm topology-resolution envelope;
- permit deterministic merge, bridge, shorten, or collapse behavior at or
  below 50 nm while preserving topology above 50 nm;
- make filtered binary64 with outward error bounds and practical fixed-width
  wide-integer predicates the normal path;
- require spatial broad-phase curve-pair pruning;
- retain analytic line and circular-arc output; and
- isolate the exact algebraic implementation as a conformance oracle, offline
  diagnostic tool, and optional bounded fallback only.

Resource ceilings will be consolidated into one internal `SolverLimits` value.
The catalog supplies immutable hard ceilings; hosts may advertise lower
effective budgets and tests may inject smaller values. The 50 nm resolution
rule is contract behavior and is not a caller-programmable tolerance.

The logical TypeSpec shapes and packed A0 record layout remain frozen. The
solver/numeric policy and its acceptance vectors are reopened, so production
promotion returns to pending while the filtered solver design is active.
`production_solver_allowed` remains false.

The previous 1.25/1.4 nm MATZ collision observation is below the new envelope
and is no longer a required production failure. The external MATZ worktree is
not present on this machine; consumer re-review is deferred until it is restored.
No external fixture was changed in this decision slice.

This machine may also need OCCT 8.0.1 restored from the binary dependency cache
under `.deps/` before native implementation validation. The local `.env` is
generated credential state and must not be committed.

No solver dispatch or production code is enabled by this documentation update.
