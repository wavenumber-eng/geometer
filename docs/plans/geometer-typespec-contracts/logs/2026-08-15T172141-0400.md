# Log: filtered-analytic-solver-design

# Filtered solver foundation and OCCT cache restore

The first production-oriented filtered solver slice is implemented but is not
connected to operation dispatch. It adds one internal limits object, the fixed
50 nm interval classifier with 49/50/51 nm boundary tests, and a deterministic
curve-bound broad phase. The production foundation has an algebraic-fallback
limit of zero and contains no Boost multiprecision or exact-backend dependency.

The broad phase counts one-dimensional overlap on both axes and sweeps the
sparser axis. This keeps separated long horizontal or vertical PCB artwork out
of an avoidable all-pairs active scan. Dense overlap remains potentially
quadratic by geometry and fails job-locally at the candidate-pair, predicate,
or working-memory budget.

This machine restored the independently accepted OCCT 8.0.1 Windows x64 and
WASM archives into generated `.deps/` state. The native archive is MSVC ABI, so
canonical native validation uses the Visual Studio 2022 developer environment.
CMake now rejects an attempt to link that archive with MinGW. Cache lookup
accepts historical archives only through exact profiles and archive SHAs;
unrelated dependency-pin or cache-transport source changes no longer churn
future recipe keys.

Validation evidence:

- native MSVC CTest: 41/41 passed;
- WASM/Emscripten CTest: 40/40 passed;
- accumulated Rack validation: 72 tests passed across native foundation,
  Python, TypeSpec, contract documentation, and browser WASM;
- focused promotion-manifest and OCCT-cache tests: 35 passed;
- Ruff, clang-format, and diff checks passed; and
- native and WASM OCCT 8.0.1 install/version verification passed.

The new WASM test was added to the repository-wide CommonJS `.cjs` executable
test policy after its first run exposed Node's package-level ESM interpretation;
the corrected full WASM rerun passed. Generated Emscripten, OCCT, download, and
credential state remains ignored.

The next solver slice owns filtered line/line, line/circle, and circle/circle
narrow-phase predicates plus deterministic uncertainty handling. It also owns
splitting the retained native exact sources into an explicit oracle target;
WASM already uses that target boundary, while the native library still carries
the pre-pivot combined source list. Production dispatch remains disabled.
