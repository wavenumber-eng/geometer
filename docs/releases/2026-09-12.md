# Geometer 2026.9.12

Release identity: `v2026-09-12`; Python/runtime and Rust/TypeScript client
version `2026.9.12`; C ABI generation `20260912`.

## Larger illustration inputs

The executable and generic-operation JSON envelope grows from 8 MiB to 32 MiB.
Structured JSON attachments now decode against the larger limit declared for
each operation: 256 MiB for illustration mesh collections and 64 MiB for
optional HLR linework. This fixes complex STEP illustrations whose tessellation
is valid but whose many source-face mesh records exceed the ordinary envelope.

The native illustration candidate-comparison guard grows from 20 million to
100 million. Complex valid models can therefore retain the default global
same-color surface fusion instead of being omitted or requiring an unfused SVG.
Triangle, visibility, SVG-size, attachment, frame, and aggregate memory limits
remain independently enforced.

Install `wn-geometer==2026.9.12`. Use matching generated clients and runtimes;
the negotiated catalog and C ABI generation advance together. OCCT remains at
8.0.1 and does not need rebuilding for these changes.
