# Log: factor-selection status and bound remediation

Independent review accepted the completeness of the Kronecker enumeration but
found three integration gaps. Factor/root selection now returns an explicit
`needs_refinement` status when an otherwise valid interval contains multiple
candidate roots; this is distinct from hard resource exhaustion and is tested
by refining the same selection to a unique successful result.

All new factorization work estimates use checked `uint64` addition and
multiplication, including evaluation, interpolation, coefficient growth, and
fixed logical-storage reservations. Overflow maps to the typed
`resource_limit_exceeded` outcome. A high-storage, low-work regression now
executes part of divisor/evaluation work, exhausts before irreducibility can be
claimed, rolls temporary storage back, and retries against the same monotonically
consumed work budget. The same tests run natively and under Emscripten.

Canonical value construction, DAGs, codecs, and production solver integration
remain gated pending independent acceptance of this remediation.
