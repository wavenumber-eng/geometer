# Release Notes: 2026-08-18

## `2026.8.18`

### Analytic planar Boolean A0 candidate

- Adds deterministic packed request/result support for ordered add, subtract,
  and add planar geometry with exact line and arc boundaries.
- Returns final regions, outer rings, holes, islands, and effective contributor
  and subtraction provenance without requiring downstream renderers to recreate
  Boolean policy.
- Provides the same governed operation through native C++, the C ABI,
  executable IPC, Python, TypeScript, Rust, and browser WASM transports.
- Includes bounded solver accounting, strict packet validation, deterministic
  normalization replay, and native/browser cross-transport parity gates.

The checked-in solver and RT PWR4 evidence remain release-candidate material.
Production publication is gated on a clean, attested build from the exact
release commit passing the portable real-board qualification. CPU model and the
1-second/512-MiB target are comparative observations, not release gates; the
hard release ceiling is 5 seconds and 1 GiB. These notes do not claim that the
clean qualification has already occurred.

### Packaging and qualification

- Python wheels bundle the native executable and its deterministic build
  attestation. Installed-wheel validation exercises both existing STEP/model
  operations and the typed analytic client.
- The governed RT PWR4 request is checked in as geometry-only MIT-licensed
  qualification evidence. Source CAD is not included.
- The optional OCCT binary dependency cache remains generated state under
  `.deps/`; cached OCCT archives and credentials are not release artifacts.
