Restore additionally accepts the bounded edit-journal artifact. Journal replay is not a generic file import: it requires exact source, normalized B-rep, target-inventory, OCCT-version, and transaction-count preconditions and rejects a mismatched source before replay.

Save validation binds the requested carrier to the emitted artifact carrier. Restore accepts both declared STEP media types, binds exact attachment descriptors to bytes, and validates the reported source and replayed transaction count against the request preconditions.

A capability record reports save, restore, authored payload, and topology-link posture independently as supported, experimental, or unsupported.
