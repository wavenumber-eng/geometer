# Release Notes: 2026-09-04

## `2026.9.4`

### Fast vector HLR and illustration

- Adds governed Fast vector HLR for STEP models and indexed meshes through the
  native API, executable IPC, browser WASM, and generated clients.
- Adds production indexed-mesh packets and reusable SVG/Canvas illustration
  modules with Fast shadow outlines, exact line reconstruction,
  coplanar-seam suppression, and normalized model transforms.
- Qualifies native and browser-WASM geometry/count parity over the embedded
  STEP corpus, including large-model browser execution.

### Resolution-bounded analytic recovery

- Coalesces capsule endpoints only when their authored coordinates differ by
  no more than 1 micrometer, allowing common PCB routing overlaps and
  sub-micron source noise to complete without hiding the adjustment.
- Reports `resolution_coalesced`, the exact number of coalescences, and the
  maximum adjustment in nanometers.
- Replays the captured Yoshi copper request byte-identically through native and
  browser WASM: 7,996 result bytes, SHA-256
  `9eefc8d66e929c38ca19046e5351638028634d01c192eeeada22625a818fae06`,
  one expected recovery warning, and no failed jobs.

### Platform boundary

- Native geometry, rendering, HLR, illustration, executable IPC, and packages
  remain supported on Windows x64, Linux x64, Linux ARM64, and macOS ARM64.
- The experimental hard-contained topology worker supervisor is supported on
  Windows and Linux. Native macOS process containment is tracked in
  [issue #25](https://github.com/wavenumber-eng/geometer/issues/25); topology
  value APIs and rendering on macOS are unaffected.
