# Release Notes: 2026-06-09

## `2026.6.9`

### Breaking Projection Schema Change

- Projection JSON now uses `geometry.projection.b0`.
- The former `simple` projection mode is removed. Use `outline` for assembly
  projection silhouettes.
- Projection views now expose `modes.outline`, `modes.detail`, and
  `modes.bbox`.

### Added

- Added mesh-shadow outline extraction for assembly projection use cases.
- Added projected bounding-box geometry as a cheap `bbox` projection mode.
- Added planar batch solve JSON ring output for Python/FEM consumers.
