# Release Notes: 2026-06-23

## `2026.6.23`

### Linux Wheel Compatibility

- Linux x64 and Linux ARM64 release wheels are built on Ubuntu 22.04 so the
  bundled native executable targets GLIBC 2.35 instead of inheriting the newer
  GLIBC 2.39 baseline from Ubuntu 24.04 runners.
- Native OCCT dependency caches now include the Linux glibc baseline in the
  cache recipe, and GitHub Actions cache keys include the runner image label.
